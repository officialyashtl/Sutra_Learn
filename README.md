# SUTRA LEARN

**Student Understanding, Targeted Reinforcement & Adaptation**

SUTRA LEARN is an adaptive learning platform designed to help students
strengthen prerequisite concepts, develop understanding through guided
practice, and progress to more challenging learning activities.

## Initial MVP

- Class 8 Mathematics
- Linear equations and prerequisite concepts
- Bridge Back, Scaffold, and Stretch learning paths
- Evidence-based recommendations
- Teacher dashboard and intervention controls
- Offline-ready learning with safe synchronization

## Planned Technology

- Frontend: React, Vite, TypeScript
- Backend: Python, FastAPI
- Database: SQLite
- Offline storage: IndexedDB and Service Worker
- Frontend hosting: Vercel
- Backend hosting: Render
